# Contributing

Thanks for contributing. This project is intentionally **high-signal**.

## Principles
- Prefer **tradeoffs over rules**
- Prefer **small pages over large pages**
- Include a **“When not to do this”** section
- Cite sources where appropriate

## Ways to contribute
- **Issue:** propose an improvement or report a gap
- **PR:** make a concrete change
- **Discussion:** debate approaches and share constraints

## Pull request checklist
- [ ] This change improves decision-making or reduces user friction
- [ ] The page is short enough to prune later
- [ ] Examples are concrete (not generic)
- [ ] Links are credible and stable
