# Contribute

This site is meant to stay **high-signal**. Contributions are welcome, but they must be:
- grounded (clear source, example, or “why”)
- prunable (short enough to delete later if it ages)
- decision-focused (tradeoffs > slogans)

## How to contribute
- **Suggest** improvements via Issues
- **Discuss** approaches via GitHub Discussions
- **Change** content via Pull Requests

## Style of contributions
- Prefer **short** pages over mega pages
- Include a “**When I would *not* do this**” section
- Avoid “best practice” language unless you define context and constraints

## Adding a new page
1. Create the Markdown file under `docs/`
2. Link it from the relevant index page
3. Keep the format consistent with other pages

## Code of conduct
Be constructive. Critique ideas, not people.
