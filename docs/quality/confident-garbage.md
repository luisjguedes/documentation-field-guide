# Confident garbage: the most dangerous documentation failure

## What it is
Text that is:
- fluent
- well structured
- confidently stated

…and fundamentally useless.

## Why it’s dangerous
- Readers trust it
- It scales easily
- It survives reviews
- AI generates it effortlessly

## How it enters systems
- “We should add an overview”
- Over-summarizing instead of deciding
- Writing to sound complete instead of useful

## Detection test
Ask:
- What action does this enable?
- What decision does this change?
- What mistake does this prevent?

If the answer is “none,” delete it.

## My rule
**Silence is better than confident irrelevance.**

## Editorial safeguard
Require every page to declare:
- primary user
- primary task
- success condition
