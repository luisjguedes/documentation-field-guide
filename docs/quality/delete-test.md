# The delete test

The senior skill is not “writing more.”

The senior skill is recognizing a paragraph that is fluent, confident, structurally correct—**but fundamentally void of relevance**—and deleting it without replacing it.

## Why this matters
- Useless text costs trust.
- Confident irrelevance scales faster than mistakes.
- AI makes this worse by generating plausible filler at speed.

## How to apply the test
Ask, for each paragraph:
1. Does it change a user decision or action?
2. Does it reduce ambiguity?
3. Does it prevent a known failure mode?

If the answer is “no,” delete it.

## Replacement rule
Only replace deleted text if you can replace it with one of:
- a step
- a constraint
- an example
- a warning
- a measurable success criterion
