# Documentation Field Guide

Decision frameworks, failure modes, and delivery patterns for technical documentation at scale.

**Not exhaustive. Not universal. Intentionally pruned. Built for real constraints.**

## What this is
This site is designed to read as a *staff-level artifact*: opinionated defaults, tradeoffs, and practical templates you can use to make documentation decisions under pressure.

## What this is not
- Not a giant link dump
- Not “everything you need to know”
- Not a curriculum

## Local preview (recommended)
1. Install Python 3.10+
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Run:
   ```bash
   mkdocs serve
   ```
4. Open the local URL shown in the terminal.

## Publish on GitHub Pages
1. Push this repo to GitHub
2. In **Settings → Pages**, set **Build and deployment** to **GitHub Actions**
3. The included workflow will deploy automatically on every push to `main`.
